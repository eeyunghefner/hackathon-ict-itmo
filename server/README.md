# Backend (server) — README

## Структура server/app

- **database.py** — инициализация подключения к базе данных, создание движка SQLAlchemy, сессий и базовой модели.
- **main.py** — точка входа FastAPI-приложения, подключение роутеров.
- **models/** — директория для моделей ORM (SQLAlchemy), описывающих таблицы базы данных.
- **repositories/** — слой доступа к данным: функции для работы с БД (CRUD-операции).
- **routers/** — роутеры FastAPI: определяют эндпоинты API, подключают обработчики.
- **schemas/** — Pydantic-схемы: структуры запросов/ответов API, валидация данных.
- **services/** — бизнес-логика приложения, сервисные функции, которые используют репозитории.

## Правила добавления новых файлов

- **models/**: добавляйте новые файлы для каждой новой таблицы/модели. Имя файла = имя сущности (например, `user.py` для модели пользователя).
- **repositories/**: создавайте отдельный файл для каждого типа сущности (например, `user.py` для работы с пользователями).
- **routers/**: для каждого нового набора эндпоинтов создавайте отдельный файл-роутер (например, `user.py` для роутов пользователей) и подключайте его в `routers/__init__.py`.
- **schemas/**: отдельный файл для каждой сущности (например, `user.py` для Pydantic-схем пользователя).
- **services/**: выносите бизнес-логику, не связанную напрямую с БД, в отдельные сервисные файлы по сущностям.

**Общие рекомендации:**
- Не смешивайте бизнес-логику, схемы и работу с БД в одном файле.
- Используйте явные и осмысленные имена файлов и классов.

## Локальный запуск проекта

1. **Клонируйте репозиторий и перейдите в папку server:**
	 ```bash
	 cd server
	 ```

2. **Создайте файл окружения:**
	 - Скопируйте `.env.example` в  `app/.env` с вашими данными для использования сервисов.

3. **Запустите сервисы через Docker Compose:**
	 ```bash
	 docker-compose up -d --build
	 ```
	 - Приложение будет доступно на http://localhost:8000

4. **(Альтернатива) Локальный запуск без Docker:**
     - Создайте виртуальное окружение
         ```bash
		 python3.12 -m venv .venv
		 ```
     - Активируйте виртуальное окружение
         ```bash
		 source .venv/bin/activate
		 ``` 
	 - Установите зависимости:
		 ```bash
		 pip install -r requirements.txt
		 ```
	 - Запустите сервер:
		 ```bash
		 python -m uvicorn app.main:app --reload
		 ```

## Alembic: миграции базы данных

- **Создать новую миграцию:**
	```bash
	alembic -c migrations/alembic.ini revision --autogenerate -m "описание изменений"
	```
- **Применить все миграции:**
	```bash
	alembic -c migrations/alembic.ini upgrade head
	```
- **Откатить последнюю миграцию:**
	```bash
	alembic -c migrations/alembic.ini downgrade -1
	```
- **Путь к конфигу Alembic:** `migrations/alembic.ini`

**Важно:**  
- Для автогенерации миграций все модели должны быть импортированы в `app/models/__init__.py`.
- При запуске через Docker миграции применяются автоматически перед стартом приложения.
- FastAPI автоматически создает API документацию. Посмотреть ее можно через `http://localhost:8000/docs` или `http://localhost:8000/redoc`
