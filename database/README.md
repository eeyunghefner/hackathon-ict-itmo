## Структура:

### schema.sql

Файл содержит DDL-скрипт создания структуры базы данных.

Чем помогает файл:

 - позволяет создать БД без запуска backend

 - помогает быстро посмотреть структуру БД
 
 ### seed.sql

Файл содержит тестовые данные.

Используется для:

 - демонстрации работы системы

 - тестирования

 - быстрого заполнения БД
